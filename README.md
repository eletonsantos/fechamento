# Política de Privacidade

Política de privacidade da extensão **IA Assist — Fechamento** para Google Chrome.

Publicada via GitHub Pages para atender à exigência de URL pública da
Chrome Web Store.

- Página: `index.html`
- Endereço publicado: https://eletonsantos.github.io/fechamento/

Ao alterar o comportamento da extensão — novos domínios, novos dados lidos —
esta política precisa ser atualizada junto, e a data no topo revisada.
