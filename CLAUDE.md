# Política de Privacidade — Extensão Fechamento

## 1. Visão geral

Página estática de política de privacidade da extensão Chrome [IA Assist — Fechamento](../Extensao-Fechamento/CLAUDE.md), publicada via GitHub Pages para atender à exigência de URL pública da Chrome Web Store.

## 2. Estado atual

Publicada e ativa: **https://eletonsantos.github.io/fechamento/**

## 3-8. Arquitetura / Tecnologias / Como executar / Variáveis / Integrações / Banco

HTML estático puro (`index.html`). Sem build, sem dependências, sem backend.

## 9. Decisões importantes do projeto

**Este repositório é intencionalmente público** — GitHub Pages exige repositório público (no plano gratuito) para servir a página, e a Chrome Web Store exige uma URL pública de política de privacidade. Não tornar privado sem substituir a forma de publicação.

## 10. Regras para futuros desenvolvimentos

Sempre que o comportamento da [Extensão Fechamento](../Extensao-Fechamento/CLAUDE.md) mudar (novos domínios acessados, novos dados lidos), **esta política precisa ser atualizada junto**, com a data no topo revisada (regra já registrada no `README.md` deste projeto).

## 11. Histórico importante

2 commits ("Add files via upload") — repositório simples, mantido via upload direto pela interface do GitHub, não por `git clone` + commits locais até esta migração (11/09/2026).

## 12-14. Próximas etapas / Arquivos críticos / Deploy

Nenhuma pendência. `index.html` é o único arquivo relevante. Deploy é automático via GitHub Pages a partir deste mesmo repositório — nenhuma ação de build necessária.

## 15. Migração Windows → macOS

Nenhuma dependência — HTML estático. Nada a ajustar.
